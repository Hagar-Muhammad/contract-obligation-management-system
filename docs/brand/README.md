# ConTrack brand

**ConTrack** is the product name of the Contract & Obligation Management System.

| Asset | Use |
|---|---|
| [`contrack-logo.svg`](contrack-logo.svg) | Logo with wordmark, light backgrounds |
| [`contrack-logo-dark.svg`](contrack-logo-dark.svg) | Logo with wordmark on the navy brand background |
| [`contrack-mark.svg`](contrack-mark.svg) | Mark only: favicon, app icon, small spaces |

In the app the logo is the `Logo` / `LogoMark` component (`frontend/src/components/Logo.tsx`), so it always matches
these files.

## Concept

An open **C** — the track a contract runs along — that closes on a **check**: an obligation fulfilled on time.
The mark is two strokes only, so it stays recognisable at 16 px (browser tab).

## Colours

| Token | Hex | Used for |
|---|---|---|
| Navy | `#0B2545` | Header background, "Con" on light backgrounds |
| Blue | `#1D4ED8` | The C on light backgrounds; primary buttons and links (Ant Design `colorPrimary`) |
| Light blue | `#60A5FA` | The C on dark backgrounds |
| Green | `#059669` / `#047857` | The check and "Track" on light backgrounds (contrast-safe) |
| Light green | `#34D399` | The check and "Track" on dark backgrounds |

## Name in Arabic

The name stays **ConTrack** (Latin) in both languages; the Arabic interface shows the descriptor
"إدارة العقود والالتزامات" beside it.
